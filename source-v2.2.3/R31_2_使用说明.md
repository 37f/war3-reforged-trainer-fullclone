# v2.2.3 FullClone R31.2-Test 使用说明

本版以你提供的 **v2.2.3 / e4930f5e0739 源码**为基础，接回此前 R30 累计扩展。原作者的新界面、3.0 扩展背包、装备、天赋、字段编辑、存档提取、地图脚本工具及原有快捷键保留。

本版程序为 `War3ReforgedTrainer-v2.2.3-FullClone-R31.2-Test.exe`，文件版本 `2.2.3.312`。这是独立测试版，不覆盖作者的 `War3ReforgedTrainer-v2.2.3-B8CE00485658.exe`。

本版继承R31.1的快捷键和队伍结果核对修复，并按本次要求移除“玩家直接胜利”。详情见同目录的 `R31_2_更新说明.md`。

## 开始使用

1. 保存游戏进度，关闭其他修改器。
2. 进入地图后打开本版程序并连接游戏。
3. 在“大象 → 经典功能”上方找到 **FullClone 扩展**。原作者的经典功能仍在该页下方。
4. 使用游戏内快捷键时，开启全局快捷键总开关，在“大象 → 全局快捷键”勾选相应功能。
5. 同一时间只运行一份修改器。原队伍、控制状态和碰撞切换记录只属于当前地图、当前连接；重新连接、切图或退出程序后不跨地图恢复旧指针。

## 复制、创建与归属

“启用面板复制归属”默认关闭。

| 操作 | 关闭开关 | 开启开关 |
| --- | --- | --- |
| 面板复制、Ctrl+B | 保留源单位归属 | 按“给自己 / 给选中单位所属玩家 / 给指定玩家”选择 |
| 大量复制、Ctrl+N | 保留源单位归属 | 按同一面板选择 |
| 呼叫增援、Ctrl+K | 作者原来的本地玩家创建逻辑 | 按同一面板选择 |
| 面板手动创建单位 | 作者原逻辑 | 按同一面板选择 |
| Ctrl+A 复制给自己 | 始终给自己 | 始终给自己 |

指定玩家下拉列表包含玩家1～24、中立敌对（玩家25）、中立被动（玩家28）。普通玩家槽位在地图中未启用时，提示“没有所属玩家”。

复制不要求预先读取单位。完整复制复用作者 **3.0 完整状态事务**，保留该版本对技能、英雄成长、普通背包、扩展背包、装备位置和天赋记录的处理。地图异常技能仍可能被作者逻辑跳过；跳过会提示，不承诺所有地图技能逐项无损。

给指定玩家复制使用独立包装入口，在第一次创建副本时就使用目标归属，不先创建给自己再转交。批量操作失败时不会自动重放，也不删除前面已经成功创建的副本。

## 玩家、控制与队伍

| 功能 | 操作 |
| --- | --- |
| 把选中单位交给指定玩家 | 选择“目标玩家”，按 Ctrl+I+U，或点击对应按钮 |
| 控制 / 恢复选中单位所属玩家 | Ctrl+I+O，再次按下恢复；不转移单位归属 |
| 应用队伍外交模板 | 选中该玩家任意单位，选择队伍1～12或两个中立模板，按 Ctrl+F1 |
| 恢复真正原队伍关系 | 点击“恢复真正原队伍” |
| 查看玩家名字与队伍 | 点击“读取选中玩家与队伍”，或勾选“每秒监视玩家名字和队伍” |

队伍功能与旧扩展一样，套用**外交关系模板**。原生队伍编号单独显示，不把中立槽位或原生 `-1` 猜成普通队伍。连续切换多个模板后，恢复仍使用本次地图第一次切换前保存的全部双向联盟标志。控制状态也在第一次写入前记录，部分写入失败时保留恢复依据。

监视显示玩家编号、实际名字及队伍。名字读取失败不会阻断编号和队伍；中立敌对、被动为空名字时省略“名称暂无法读取”。选中单位在读取中变化时，迟到结果不继续显示。

## 新增和调整的单位快捷键

| 快捷键 / 功能 | 用法 |
| --- | --- |
| Ctrl+U+8 替换单位 | 右侧填写四字符单位ID，默认 `zhyd`；在原位置、原归属创建目标类型并移除原单位 |
| Ctrl+空格 单位生命魔法全满 | 恢复选中单位生命及其可用魔法；零魔法单位跳过魔法部分 |
| Ctrl+F+H 复活阵亡英雄 | 选中任意玩家单位，将该玩家阵亡英雄复活到鼠标地面位置 |
| Alt+L 碰撞切换 | 第一次关闭当前选中单位碰撞，再次按下开启 |
| Ctrl+Q 英雄升级 | 默认每次升1级；勾选“自定义”后按原输入值设置等级 |
| Alt+Q 永久三围 | 默认力量、敏捷、智力各加2；勾选“自定义”后按原输入值设置 |
| Alt+空格 金矿黄金 | 在扩展面板填写金额，选中金矿执行；非金矿跳过 |
| 设置单位颜色 / 设置玩家颜色 | 颜色1～24；不修改归属和队伍 |

“自定义”未勾选时，快捷键数值框为灰色禁用状态，仍能看见原默认数字。原面板的“设置英雄等级”按钮继续使用面板输入值。

替换沿用R30语义：保留归属、位置、朝向及生命/魔法比例、资源余量；英雄替换为英雄时保留经验，转移原六格背包中的物品实例。荒芜金矿使用专用创建入口。创建或物品转移失败时，在移除原单位前尝试退回已转移的物品。

替换属于创建新实例并移除原实例，不是只改显示模型；不承诺保留原单位的脚本引用、任务绑定及3.0扩展背包、装备或天赋。地图脚本可能对新建、移除单位作出反应。完整复制与替换单位是不同的操作。

## 地狱火、物品聚集与胜利

- **Ctrl+F2**：在鼠标地面位置真实施放 `AUin`，归自己。使用不可见、不可选的临时施法载体，随后清理；不使用显示步兵的定时生命倒计时。运行中的游戏可继续播放技能自己的陨石、落地、眩晕与召唤流程；不要在暂停状态执行施法。
- **Alt+F2**：将当前地图可见、存活、未被单位持有的地面物品聚集到鼠标位置。移动原实例，不重建、不修改数量；背包、扩展背包、商店库存与隐藏物品不参与。先固定本次物品集合，之后才移动。部分失败不自动重放、不猜测回滚。
- **Alt+B**：仅使用作者原来的胜利秘籍 `allyourbasearebelongtous`。已移除扩展面板的胜利方式选择及“玩家直接胜利”执行入口。Alt+B沿用作者的默认未勾选状态，需在全局快捷键列表中勾选后使用。

本版这些操作尚需游戏内逐项验收。当前验证只读核对了接口和过滤流程，没有执行复制、换队伍、施法或聚集。

## 自定义 ID：读取当前地图

进入“典籍 → 自定义地图数据”，点击 **读取当前地图**。也保留作者的选择战役、地图文件方式。

当前图入口复用作者的文件目录解析器，自动定位本地档案；战役只保留当前章节和战役共用数据，支持单位、技能、物品和科技。结果来自静态物编和数据表，脚本运行后临时改写的实例值不在这个目录里。

切图或连接变化会使当前图结果失效，需重新读取。通用 ID 检索、3.0 装备和英雄技能目录仍使用作者新版原目录。

## 任务与条件

1. 打开“典籍 → 任务与条件”。打开页面本身不开始检测。
2. 首次点击 **开始检测**；此后按钮为 **重新检测**。
3. 选择主线或支线，查看地图原任务说明、子目标以及易读的完成、失败条件。未能解析的部分单独列出。
4. 默认不显示区域。勾选 **触发位置** 后才显示触发前位置、条件地点及坐标按钮。
5. 多地点分别点击；只有一个地点的任务，在勾选位置后点击条目可直接定位。没有地点显示“无位置”，不可点击。
6. 位置包括能静态确认的区域、单位、物品掉落或刷新来源、商店/NPC、建筑、可破坏物、镜头预设和计时关联点。单位初始坐标标明“脚本初始位置，非实时”。
7. 完成、失败状态在有可靠来源和唯一标量任务变量时每秒同步；不能唯一匹配则显示“状态未确认”，不凭标题或原说明猜测。

独立相机入口只移动本地视角。没有任何“直接完成任务”、触发任务奖励或执行地图脚本的功能。

**目前自动地图来源与任务变量布局仅对本次核对的精确游戏版本 `3.0.1.24371` 接入。**其他小版本可以先使用指定文件分析。Lua、自建任务系统、动态数组任务和无法唯一绑定的任务明确提示未确认。

本机的 `Allow Local Files` 保持原值1，没有改注册表。官方安装包基础脚本可以阅读，但本地覆盖优先级未确认时，不能据此声称实时状态已经绑定；相应状态显示“状态未确认”。

- 从“荣耀之丘”切换到《雷克萨传奇》第一章后，实际读取当前章节 `K-Orgrimmar.w3x`，解析出22个任务条目。连续三次读到“可怕的发现”为“进行中”；未创建及无法唯一绑定的任务保留“状态未确认”。本轮未触发任务完成或失败，不能据此声称状态切换效果已经实测。

没有迁入此前撤销的任务执行、名称修改、旧版失效游戏速度补丁和旧建造加速实验。作者v2.2.3本来已有的功能继续保留。
