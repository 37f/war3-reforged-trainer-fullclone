# v2.2.3 FullClone R31.11-Test 更新说明

本版在「队伍与玩家」增加“当前外交模板”分组，其余行为与 R31.10 相同。

## 新增显示

- 分组方式下拉列表增加 **当前外交模板**。
- 该分组按照大象“加入队伍”套用、并记在本次地图会话里的外交模板排列，例如“队伍 1”“中立敌对”。
- 尚未套用或已经“恢复真正原队伍”的活动玩家列在“未套用外交模板”。
- 表格和玩家详情同步显示当前外交模板；原生队伍分组仍按 R31.10 的首次确认名单，不会因为加入队伍而改组。

## 未改动的部分

- 加入队伍仍然只套用外交关系模板，不调用 `SetPlayerTeam`，也不改共享控制位。
- 原生操作号、桌面协议与生产桥接 DLL 均与 R31.8／R31.10 相同。
- 本页仍然只读，不新增写入路径。

## 验证记录

- 209 项 Python 测试通过，新增 2 项：外交模板按玩家槽位而不是单位归属句柄分组；恢复后回到未套用。
- 本版为独立 Test 版，未覆盖作者原程序，也未上传 GitHub。
