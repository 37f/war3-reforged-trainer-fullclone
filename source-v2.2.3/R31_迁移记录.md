## 构建

使用Python3.12、Node.js以及Windows x64 clang。依赖和原生基线准备沿用作者说明；CascLib需为配套文件，哈希在 `war3_fullclone_casc.py` 中固定。

```powershell
python -m pip install -r requirements-build.txt fonttools brotli pytest
python tools/prepare_build_baseline_223.py --from-file "原作者EXE完整路径"
npm ci --prefix frontend
npm run fonts:fetch --prefix frontend
npm run fonts --prefix frontend
npm run build --prefix frontend
python -m pytest tests -q
.\tools\build_fullclone_bridge.ps1 -CompilerPath "LLVM-MinGW的clang.exe完整路径"
python tools/build_fullclone_r31.py --bridge-image tools/war3_bridge_24268.dll
python tools/build_fullclone_r31.py --verify-only
```

运行构建器前，须从当前C源码编译生产桥接，不能将 `war3_bridge_24268.upstream.dll` 重命名冒充新桥接。测试夹具不进入生产程序。源包包含本次编译的桥接及其源码，原编译参数和验证结果在交付验证记录中。
