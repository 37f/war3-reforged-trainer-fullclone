# v2.2.3 FullClone R31.1-Test 修复说明

本版针对R31实测反馈修复，程序单独命名为 `War3ReforgedTrainer-v2.2.3-FullClone-R31.1-Test.exe`，Windows文件版本为 `2.2.3.311`。保留R31与原作者EXE。

## 快捷键与按钮行为不一致

根因已在实际桌面类组合中确认：原命令类继承扩展类，同时又定义自己的同名方法，原 `hotkey_actions` 覆盖了扩展回调表。因此扩展快捷键没有绑定，Ctrl+Q、Alt+Q及Alt+B仍走作者原逻辑，复制操作也绕开扩展归属选择。

修复为让扩展类位于原命令类前方，保留原实现作为回退。原命令方法内容不变。新增测试从真实 `DesktopBridgeApi` 创建应用，核对77个回调、启用列表、按键分发及按钮分发，不再只测孤立扩展方法。

| 反馈 | 本版处理 |
| --- | --- |
| Ctrl+B / Ctrl+N 不服从面板 | 快捷键与扩展按钮进入相同复制命令；关闭归属开关保留源归属，Ctrl+A始终给自己 |
| Ctrl+I+O 按钮有效、快捷键无效 | 控制/恢复回调正式绑定到快捷键 |
| Ctrl+Q 未勾选时不能升1级 | 进入逐英雄加1逻辑；自定义勾选后继续使用作者的输入值设置 |
| Alt+Q 未勾选时不能各加2 | 进入永久三围各加2逻辑；自定义勾选后继续使用作者的输入值设置 |
| Alt+B 玩家直接胜利无效 | 单选项现在决定实际回调；玩家模式进入独立胜利入口，作者模式保留秘籍逻辑 |
| Alt+空格、Ctrl+F2、Alt+F2 快捷键无效 | 金矿、地狱火、聚集物品的回调正式绑定 |

## 队伍关系已变化但出现操作未完成

R31日志确认独立队伍操作 `action=9` 收到访问异常 `0xC0000005`。日志本身不能确定异常前哪些标志已生效，因此不能仅隐藏报错。

本版先跳过已符合请求的标志。每次实际写入后通过独立读取核对；仅对访问异常且确认标志从旧值变为目标值的情况继续处理，保留异常计数与代码，不重放该写入。其余异常或读回不一致仍报告失败。全部写入后再次核对完整双向关系，避免后一次写入影响前面的结果。

首次原关系快照仍在写入前保存，失败后保留恢复依据。没有新增旧版中立内存补丁，也没有改变作者的读取、适配JSON或原有native操作实现。

## 使用

1. 关闭R31，打开新文件 `War3ReforgedTrainer-v2.2.3-FullClone-R31.1-Test.exe` 并连接游戏。
2. 打开全局快捷键总开关，在“大象 → 全局快捷键”勾选对应功能。Alt+B沿用作者默认不勾选，需要手动勾选。
3. 复制归属、目标玩家、自定义选项和胜利模式按需要重新选择。
4. 地狱火和物品聚集执行时将鼠标放在游戏目标地面。组合键需同时按住，例如Ctrl+I+O。

队伍恢复记录只属于原程序的当前连接。关闭旧程序不会把其原关系快照带入新程序；若要核对真正初始关系，使用改队伍前的存档或新地图。
