# R23 测试版：任务检索与原完成流程

基于 FullClone R22 和作者 v1.0.19 / `4124cd5`。仅针对已核对的 Warcraft III **2.0.4.23745 x64**。旧版功能、读取入口、快捷键和原操作号保留；本版配套 helper 协议升级为 **79**，新增任务操作 320–322，以及只读的游戏来源设置校验 323。

**本版已通过离线回归、冻结包检查、实际游戏内绑定检查，以及独立测试图中的原流程奖励和两秒延迟后续测试。该结果限于已验证的流程结构；复杂或来源未确认的任务仍会拒绝执行。**

## 检索任务

1. 进入地图后打开 R23-Test，连接游戏，进入“任务与条件”页。
2. 页面自动确认当前来源并检索 JASS，无需选中单位或手选章节。自定义战役章节、独立 `.w3m/.w3x` 和可确认来源的官方章节共用页面。
3. 左侧选择任务，右侧查看实际条件、调用链、行号和解析缺口。支持搜索任务名、变量、函数或条件文本。
4. “任务定义”包含可能尚未创建的任务；它不是当前任务进度。相同名称的不同任务不合并。胜败结算点和覆盖说明不能作为可执行任务。

官方章节从本机 CASC 读取，不在线补齐。已核对实际章节路径、安装构建、游戏持有的数据文件和内容一致性；这仍未证明所有语言／模组覆盖层的最终优先级，因此当前显示为**官方安装基础脚本分析，原流程执行禁用**。基础 WTS 可能为英文；不会把基础英文文本称为已读取游戏当前中文本地化。来源不唯一、版本不符、多分段资源、Lua 或无法分析的脚本会明确提示。

## 完成指定任务

1. 先阅读所选任务的条件与证据，确认要测试的任务，并自行保存可恢复的进度。
2. 点击“检查完成入口”。程序先识别拥有奖励与后续的原流程，再在游戏线程核对当前任务实例、原触发器、注册动作、函数引用、来源及会话。
3. 校验成功后，“完成此任务（原流程）”短暂启用，运行时证明有效期为两秒。过期后重新检查；选择其他行、过滤掉任务、来源或连接变化都会撤销证明。
4. 点击完成按钮才会派发原流程。选择任务、刷新、切语言和检索本身都不会触发完成。
5. 原流程已派发但尚未读回完成时，可点“读取执行状态”。此按钮只查询原请求，不会再次执行。

这里执行经过确认的原触发器流程，**不使用单独设置完成标志来冒充奖励或剧情已实现**。动作依赖未确认的事件响应、条件、上下文、动态调用、复杂分支或不明确的注册关系时，本版拒绝执行并显示原因。可用 native 不等于其上下文已核对；未分类的 getter 也会拒绝。当前所有官方基础资源的原流程执行均因覆盖层尚未完全确认而禁用；两个已核对的官方第一章还分别包含复杂上下文，不能仅靠解除来源保护就执行。

## 执行结果

| 状态 | 含义 |
| --- | --- |
| 派发前拒绝 | 当前请求没有启动原流程，显示具体原因。 |
| 原流程已派发，尚待核对 | 已运行原入口，可能还有等待或异步后续。 |
| 已读回任务完成状态 | 观察到任务完成标志；奖励和后续仍需在游戏里核对。 |
| 结果未知 | 请求可能已执行，或执行期间换图、断开、异常、超时；禁止自动重试。 |

同一个实际任务实例只允许派发一次。账本由游戏进程持有，重连修改器、重新检索、目录令牌变化或 helper 重载均不能清除记录。记录容量满或持久状态损坏时拒绝继续。关闭页面或取消显示不会回滚已经执行的游戏逻辑。

## 本地文件覆盖设置

当 Warcraft III 的 `Allow Local Files` 启用、设置无法核对或在游戏启动后变化时，无法确认原任务脚本实际生效来源，新原流程执行会被拒绝；官方来源检索也会拒绝不明确的来源。程序不会自动修改此设置。既有自定义地图只读分析保留原方式。

程序从游戏进程内读取该设置，并将校验结果绑定到当前进程及启动时间。验证中实际遇到过修改器宿主与游戏读到不同的值，因此宿主侧读回成功不能代替游戏侧证明。无法取得游戏侧证明时会明确拒绝。

本轮测试结束后，用户已从 Windows 注册表编辑器恢复原值 `1`，并已通过界面核对；宿主侧也已恢复。其原值和恢复文件属于私有验证记录，不纳入发布包。后续要使用任务原流程执行时，需要自行将该值改为 DWORD `0`，完整退出游戏再启动；改动后的旧进程不能作为来源校验通过的依据。程序不会自动改变该设置。

## 保留与未验证项

独立测试图已实际加载并按正常资格检查各执行一次：同步任务增加100金币、给予一个 `ratf` 物品并调用子触发器；人口由5变7。延迟任务先增加50金币，约0.6秒仍未完成、约2.8秒读回完成。重连后只读查回两条执行记录，已完成任务的再次检查均拒绝，最终650金币及一个物品未重复增加。冻结 EXE 已实际连接并显示两个任务及正确脚本哈希。

所有旧 EXE 与原战役、地图、存档保留。R23 使用独立文件名，不自动上传 GitHub。未完成的建造／研究／造兵每秒推进20秒功能不在本版范围内。实际派发后换图、任意地图的复杂剧情和官方覆盖层仍未完成全面验证；测试图结果不能外推为所有任务可执行。
