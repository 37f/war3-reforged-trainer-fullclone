# R25 任务状态同步（本地测试版）

在 R24 的“任务与条件”页增加“当前状态”列。进入地图并连接后，打开该页；静态检索完成后，只读同步主线、支线任务的游戏状态。页面可见时每轮间隔约 1 秒；查询或来源校验较慢时，以实际完成时间为准，不叠加查询线程。

| 当前状态 | 含义 |
| --- | --- |
| 进行中 | 已唯一对应到游戏内任务，游戏未标记完成或失败 |
| 已完成 | 游戏的任务完成标记为真，失败标记为假 |
| 已失败 | 游戏的任务失败标记为真，完成标记为假 |
| 状态未确认 | 未创建、已销毁、句柄无法唯一匹配、查询失败，或完成与失败标记同时为真 |

选择任务后，详情开头显示当前状态、最近成功读取时间或无法确认的原因。原有目标说明、完成条件、失败条件和脚本依据继续显示。任务条目的数量／百分比以及整关胜败不属于本次状态同步。

## 启动

1. 保存游戏进度并关闭其他修改器。若本轮游戏已经连接过 R24 或更早版本，请完整退出游戏到桌面，再进入地图，避免旧 helper 的协议仍留在进程里。
2. 打开 `War3ReforgedTrainer-v1.0.19-FullClone-R25-Test.exe`，连接游戏。
3. 打开“任务与条件”。检索到主线／支线定义后观察“当前状态”。在游戏里正常完成或失败一个任务，再切回修改器核对变化。
4. 隐藏任务页会停止轮询并清除该页旧状态；重新打开后重新检索。换图、断开连接、取消检索也会清除旧状态。

## 支持范围

- 当前支持 Warcraft III 2.0.4.23745 x64。
- 通过当前地图 JASS 中可唯一识别的标量 `quest` 全局变量绑定任务。使用数组、局部变量、动态任务容器或自建任务面板的地图，可能只能显示静态条件及“状态未确认”。不按名称相同就推定是同一任务。
- 若官方战役只能读取安装包基础脚本，而本地文件覆盖开关开启，实时状态会显示来源无法确认的原因。静态报告继续保留。R25 不自动修改这个设置。
- 脚本中的完成／失败条件是静态分析；状态列读取游戏的实际任务标记。若地图只触发失败剧情却没有设置该任务的失败标记，状态列不会自行推断“已失败”。

本版只有读取，不提供完成任务、发奖励、运行任务触发器或更改任务状态的入口。

## 版本与验收

- Python 与 native helper 配对协议：81；只读任务状态操作号：324。
- 原任务执行操作 320–322 继续禁用，323 保留原来源查询。
- R25 独立命名；R24 文件及 GitHub 发布未更改。
- 构建及离线检查记录见 `R25_VERIFICATION.md`。离线检查不等于在实际战役里完成／失败任务的验收。
