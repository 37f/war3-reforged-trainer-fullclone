## 兼容处理与取舍

1. 章节原表可覆盖战役新增对象；保留战役真正的基础 ID，再合并章节字段。否则会误报正常对象冲突。
2. 旧编辑器字段尾值为不透明四字节，已从实际战役和上游读取器确认；检查长度而不强制它等于对象 ID。截断、未知类型、数量越界与多余尾部仍会拒绝。
3. WTS 注释中可有 U+001E 元数据，仅按 LF/CRLF 分行，避免将元数据误拆成新记录。正文内 `//` 保持原文。
4. 保留旧 R19.3 spec；新增独立 `War3ReforgedTrainer-FullClone-R20.spec`，避免覆盖历史 EXE。源码构建请用新入口。

原生 app worktree 工具因聊天 cwd 位于嵌套 Git 仓库外而返回 Not a git repository，故使用旁边的 Git linked worktree，未移动原工作区。分支与源码保留，未合并或发布。
