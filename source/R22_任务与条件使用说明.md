# R22：当前地图任务与实际条件

基于 v1.0.19 / 4124cd5 的 FullClone R21 扩展。本版新增独立的“任务与条件”页，保留原有单位、英雄、物品、技能、复制归属、地狱火、队伍监视及 ID 目录功能。配套 helper 仍为协议 78，没有替换旧操作含义或 native 名称/hash。

## 使用

1. 启动 Warcraft III，进入自定义战役章节或独立地图。
2. 打开 `War3ReforgedTrainer-v1.0.19-FullClone-R22-Test.exe`，点击“连接/刷新进程”。
3. 打开“任务与条件”页。该页会自动确认当前章节和档案来源，再读取脚本、字符串表并分析；无需选择战役文件，也无需选中单位。
4. 检索完成后，左侧选择任务、关卡直接胜败或“覆盖情况”，右侧查看说明、条件、调用链、变量来源、函数和行号。
5. 搜索框可检索任务名称、变量名、函数名或条件文字。例如搜索 `udg_recruits_CompletedReqs`、`CustomDefeatBJ` 或任务中文名。
6. 需要重新检测时点击“重新检索”。“取消检索”停止当前报告发布，再点重新检索可恢复。隐藏本页后不会继续全量分析；重新进入时重新验证/检索当前来源。

详情文本可选中复制。新增页面只有读取、检索、取消和显示操作，没有完成任务、触发失败或修改任务的按钮、快捷键。

## 怎样理解结果

- **任务定义**：从脚本识别的任务创建代码。包括尚未执行、尚未发现的定义；这不代表本次游戏已经创建/显示了该任务。
- **完成 / 失败 / 重置**：区分设置为 true 和 false。重置为未完成或未失败不会算成任务成功或失败。
- **关卡直接胜利 / 失败**：单独列出能确认的玩家结算调用，不硬塞到某个任务中。“失败”提示文字或函数名本身不会当成真正判负。
- **路径**：同一设置点的多条路径是备选；一条路径中的 AND/OR、否定、比较符号、事件和调用者分别保留。`== 3` 和 `>= 3` 不会混同。
- **变量证据**：显示静态初值、赋值、加减、任务条目前提等来源，不是当前计数或当前任务进度。
- **解析缺口**：动态函数名、动态对象下标、递归、循环、未知函数、未确认入口、触发器启停时序等会明确列出。“部分解析”仍可查看已确认的条件，但不表示整个地图的所有规则均已恢复。
- **同名任务**：地图可能创建两个同名 quest。请结合脚本标识、静态别名和条目区分，修改器不会仅按显示名称合并。

“覆盖情况”汇总不能确认的部分和来源证明。每份报告绑定当前游戏连接、地图会话、确切章节、脚本和字符串表 SHA-256；断线、换图或来源变化后清除旧报告。普通界面支持中英文切换，地图原文和原始代码保持原样。

## 支持范围及来源拒绝

首版支持已验证的 **Warcraft III 2.0.4.23745 x64 + JASS**。Lua、加密/不可读脚本、来源无法确认、多个冲突脚本入口、解析或资源上限错误会给出明确提示，不显示“0 个任务，完整成功”。自建 UI 的任务系统可能不使用标准 quest 接口，不能据此认定地图没有任务。

为了避免读取另一份或已修改的章节，修改器比较游戏实际持有档案和磁盘文件的身份、大小、写入时间，并检查读取前后会话。**档案写入时间晚于游戏进程启动时，会拒绝分析**：请先保存进度，完整退出并重新启动游戏，再进入该地图。不要通过改文件时间绕过核对。

不从 Campaigns 目录猜一个同名文件，也不把上一章的字符串表套到本章。如果来源无法确认，可记录页面提示用于排查。

资源限制：脚本 32 MiB、字符串表 16 MiB、读取 60 秒；词法/语法节点各 500000、函数 50000、语法嵌套 128；条件分析调用深度 64、每个目标 128 条路径、任务定义 10000、表达式树深度 128、分析 30 秒。超限不会冒充完整结果。

## 本机已核对的样例

《亡灵骑士》第一章和第三章“追捕”的实际来源和脚本/字符串表哈希已只读对照。第三章识别到 3 个任务定义（两个同名“黑潮”和“藏身处”）、2 处直接失败、1 处直接胜利。

- 扩军条目的累计检查保留 `udg_recruits_CompletedReqs == 3`，并追到三个任务条目的计数来源。
- 藏身处：进入 `gg_rct_Region_018`，并检查进入单位是否敌对于 `Player(1)`。
- 两处直接失败分别来自英雄死亡判定和指定单位死亡事件，保留等待及调用位置。
- 直接胜利继续追踪手动调用触发器的上游事件，而非显示成无条件胜利。

这些是源脚本分析和来源验证。本次没有实际杀死英雄、完成任务或触发胜败来测试地图行为，也没有重测所有旧功能的游戏效果；旧功能的保留依据为改动边界和回归测试。

旧版全部功能及快捷键说明见同目录 `V19_FULL_USAGE_GUIDE_ZH.md`，R20/R21 自定义对象及当前地图目录说明继续适用。
