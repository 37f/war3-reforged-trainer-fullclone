# 魔兽争霸 3 重制版修改器 v1.0.19 FullClone R18 完整使用说明

## 1. 适用范围

- 目标游戏版本：**Warcraft III 2.0.4.23745**。
- 本版以作者精确源码提交 `4124cd582ed624eeb85d665484755fa8cae65697` 为基础。
- 作者 v1.0.19 已取消“备用读取版”；本版同样只有一个 EXE，所有扩展功能都接入作者的持久 native helper。
- 本版没有加入“选中玩家后，建造/研究/造兵/建筑升级每秒推进约 20 秒”。`Alt+V` 仍只有作者原来的 `warpten` 快速建造/研究秘籍逻辑。
- 已移除容易造成崩溃的单位显示名称/英雄专有名称修改功能。

自动化验证只能证明源码、协议、打包文件和离线启动一致；涉及地图脚本、单位数据和玩家关系的功能仍应在单机地图中逐项验证。

## 2. 启动与连接

1. 启动 Warcraft III 并进入地图。
2. 以管理员身份运行 `War3ReforgedTrainer-v1.0.19-FullClone-R18.exe`。
3. 点击“连接/刷新进程”。
4. 需要对单位操作时，先在游戏中选中单位。复制、替换、控制、队伍、颜色、英雄复活等扩展功能会直接读取当前选择，无需先点“读取所有选中单位”。
5. 若切换地图、重开游戏或游戏 PID 改变，请重新连接。进程变化后，控制权和原队伍快照会被清除。

## 3. 复制、归属和增援

“大象功能 → 功能面板 → 创建与物品”中有“启用面板复制归属（关闭＝作者逻辑）”。

- 默认关闭：
  - `Ctrl+B 复制单位` 使用作者 v1.0.19 的逻辑，保留源单位归属。
  - 面板“复制选中单位”和“大量复制”也使用作者逻辑，保留每个源单位的原归属。
  - “呼叫增援”使用作者的本地玩家创建逻辑。
- 开启后：面板复制、大量复制、`Ctrl+B` 和呼叫增援服从“复制归属”选择：
  - 给自己；
  - 给选中单位所属玩家；
  - 给指定目标玩家（玩家 1～24、中立敌对、中立被动）。
- `Ctrl+A` 始终是“复制单位给自己”。
- “大量复制”按当前数量重复执行完整复制事务；英雄等级/经验、永久三围、可用技能点、技能和等级、生命/魔法、背包物品数量及作者已开放的物品实例字段按复制事务迁移。
- R16 修复了批量复制归属参数传递错误：面板归属关闭时保留原归属，开启并选择“给自己”时给本地玩家；`Ctrl+N` 使用同一设置。
- 某些地图会用自定义脚本重建单位、技能或背包，可能覆盖复制结果；这不是修改器读取缓存。

## 4. 玩家、控制权和队伍

- **先确认队伍（R17 新增）**：在游戏中选中该玩家任意一个单位，在“目标单位 → 加入队伍”下点击“读取队伍”。显示读取当时该单位所属玩家的队伍；勾选“监视队伍（每秒刷新）”后，切换选中单位时会自动跟随所属玩家刷新。监视默认关闭，不需要提前读取选中单位。
- 普通玩家显示如“玩家 8：队伍 4”。中立敌对和中立被动显示特殊槽位与原生队伍编号；已用本修改器套用外交模板的玩家，仅在当前双向联盟关系核对一致时显示“队伍 2（外交模板）”等。模板失效时提示“关系已变化”，避免把上次选择的队伍误当成当前队伍。
- 队伍监视只有读取操作，不修改归属、队伍、联盟或原队伍快照，也不改变下拉框中的目标队伍。没有选中单位、游戏未连接或其他操作进行中时，在该栏显示提示；切换或恢复队伍后会自动再读一次。
- `Ctrl+I+U`：把当前选中单位交给面板“目标玩家”。若地图中没有该普通玩家槽位，会提示没有所属玩家；中立敌对和中立被动使用特殊玩家槽。
- `Ctrl+I+O`：控制/恢复当前选中单位所属玩家，不改变单位归属或阵营。第一次执行会保存该游戏进程中的原控制关系，再按一次恢复。
- `Ctrl+F1`：把当前选中单位所属玩家加入下拉框指定的队伍 1～12，或套用“中立敌对队伍”“中立被动队伍”的外交模板。
- 下拉框选择“恢复原队伍”后按 `Ctrl+F1`：恢复第一次切换前记录的真实队伍和双向联盟关系。
- 连续切换多个队伍不会覆盖第一次记录的原队伍。恢复失败时快照会保留，便于重试。
- 快照按“游戏进程 + 玩家槽位”保存；重开游戏、PID 改变或关闭修改器后不能用旧快照恢复。
- 中立敌对/中立被动不是普通大厅队伍。修改器恢复的是首次记录的关系快照，而不是简单猜测为某个队伍编号。

## 5. 单位事务功能

- 替换单位：在右侧输入四字符单位 ID，默认 `zhyd`，点击“替换单位”或按 `Ctrl+U+8`。只有新单位创建且必要状态迁移成功后才删除源单位；失败时尽量清理新单位并保留源单位。
- `Ctrl+F+H`：选中任意玩家的一个单位，把该玩家全部阵亡英雄复活到鼠标位置。
- `Ctrl+空格`：把选中单位生命值加满；有魔法上限的单位同时把魔法值加满。无魔法单位不会进行无效魔法写入。
- `Alt+L`：切换选中单位碰撞。再次按会恢复。面板“开启碰撞/关闭碰撞”会与同一状态逻辑同步。
- 单位颜色：只改变选中单位显示颜色，不改变归属和阵营。
- 玩家颜色：改变选中单位所属玩家的颜色，不改变归属和阵营。

## 6. 英雄、属性和金矿

- `Ctrl+Q 英雄等级`：
  - 默认未勾选“自定义”：每按一次，按英雄当前实时等级增加 1 级。
  - 勾选“自定义”：右侧灰色输入框启用，按一次直接设置为输入等级。
- `Alt+Q 设置属性`：
  - 默认未勾选“自定义”：每按一次把选中英雄永久力量、敏捷、智力各增加 2 点。
  - 勾选后：使用输入值执行原有自定义属性逻辑。
  - 选中非英雄单位时静默无操作，不弹错误。
- `Alt+空格`：把选中金矿剩余黄金设置为输入值，默认 `100000`，允许范围 `0～1000000000`。选中非金矿单位时静默无操作。
- `Ctrl+F2`：在鼠标位置释放地狱火技能 `AUin`。本版沿用 R14 恢复的 R12 实机验证事务：临时创建本地玩家的 `hfoo` 施法载体、赋予并释放 `AUin`，再用 `BTLF` 在 6 秒后清理施法载体。地狱火由技能本身产生陨石下落、落地眩晕与召唤效果；召唤物归属按游戏技能和地图数据决定。

## 7. 直接胜利

`Alt+B 直接胜利` 右侧有两种模式：

- 使用秘籍（默认）：保留作者原来的胜利秘籍路径。
- 玩家直接胜利：对本地玩家提交游戏胜利结果，再结束当前游戏。用于某些忽略胜利秘籍的自定义战役。

建议先保存游戏。部分自定义地图可能接管胜负流程或在结束时执行自己的存档逻辑。

## 9. 风险、限制与排错

- 优先在单机、自定义地图或已备份存档中使用；不要在联网对战中使用。
- 替换、删除、爆炸、清空背包、队伍关系、控制权和结束游戏属于高影响操作。
- 地图脚本可以在修改器写入后再次修改归属、颜色、联盟、单位或英雄状态。
- 普通玩家槽不存在时会拒绝目标；中立玩家槽存在但行为受地图脚本和游戏原生规则限制。
- 若提示 native 快照失效、单位身份变化或进程变化，请重新连接并重新选择单位，不要继续使用旧状态。
- 若 Windows 安全中心阻止运行，请先核对 `SHA256SUMS.txt`，确认文件来自本次输出目录；不要通过关闭整个安全中心来解决。
- 本版不包含任何旧 FullClone 独立 helper DLL。若旁边出现旧版 helper，请不要混用，重新从发布目录复制干净版本。

## 10. R18：全光环、全被动、六神器、群星修复

- `Ctrl+Num1 全光环` / `Ctrl+Num2 全被动`：预设的 112 级改为上限，先查询地图定义的技能等级数量，实际设置到 `min(112, 地图上限)`。例如地图技能只有 3 级时设为 3，而不是越界到 112。普通手动“设置技能等级”逻辑不变。
- `Ctrl+Num2 全被动` / `Ctrl+Num3 获得 6 个神器`：允许安全地确保背包存在，保留已有背包；不开放背包基础组件的删除、重置或等级修改。六神器仍会替换原有六个物品槽，请先存档。
- `Alt+A 全屏群星陨落`：保留作者的释放路径、范围和 12 秒效果窗口。结束时不打断后来下达的新命令；临时添加的群星技能直接安全移除；已有群星只恢复本次操作仍拥有的范围改动，不覆盖地图脚本的新值。真实身份失效或引擎失败仍会报错。
- 上述四项有实际 C 分派器的离线回归测试，但 R18 尚未进行真实地图验收；请按 `R18_ELEPHANT_REPAIR_NOTES.md` 的步骤测试。
- 从旧版切换到 R18 时，先存档，关闭旧修改器并退出、重开游戏。旧 helper 可能已在游戏进程中常驻，旧失败记录不能靠替换 EXE 自动清掉。不要同一游戏进程同时连接多个修改器版本。
