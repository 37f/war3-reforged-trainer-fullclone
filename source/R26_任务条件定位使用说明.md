# R26 任务与条件：地点显示与视角定位

## 怎么点

1. 保存进度，关闭其他版本的修改器；若游戏已连接过 R25，请完整退出游戏再进入地图。
2. 启动 `War3ReforgedTrainer-v1.0.19-FullClone-R26-Test.exe`，连接游戏，打开“任务与条件”。
3. 点击任务左侧的展开箭头，可看到子目标、完成条件和失败条件。选择条件后，右侧原有解释下会列出关联地点。
4. **只有一个地点**：点击任务、子目标或条件行，即将本地视角移到该地点；也可以按 Enter。
5. **多个地点**：继续展开条件，点击具体“位置”行；或点击右侧详情中蓝色带下划线的地点说明。不会擅自选其中一个。
6. **无位置**：显示灰色“无位置”，不调用相机，也不弹错误窗口。

展开列表、自动刷新任务状态、检索完成后的默认选择均不会自动移动视角。视角定位成功后会将游戏窗口置于前台。若点击时来源或地图已变化，界面内提示重新检索，不使用上一张图的坐标。

## 位置说明

- 区域：显示脚本区域名、中心坐标、X/Y 范围。多个矩形组成的区域分别列出。
- 命名单位：显示脚本变量名、能确认的单位 ID 和**脚本初始位置**。
- 地点变量：显示可唯一解析的脚本坐标。
- 坐标使用 Warcraft III 的地图坐标：X 增大向东（右），Y 增大向北（上），不是屏幕像素。

例如“进入通关区域且指定单位死亡”可以同时列出进入区域和目标单位初始位置；直接进入某区域结算的条件会显示该区域中心与范围。

## 数据来源与限制

位置来自现有任务报告已绑定的 `war3map.j`：使用条件路径中的事件和变量引用，解析对应 `Rect`、`Location`、`CreateUnit` 等静态定义。没有额外扫描游戏进程或单位内存。任务分类、完成／失败判定及已有状态同步沿用原逻辑。

以下情况可能显示“无位置”：坐标由运行时计算、随机值、函数参数、动态数组、自建任务系统或多个冲突赋值决定；条件只有计数、聊天、计时或玩家资源；目标仅按单位类型筛选而没有唯一命名单位。

**单位位置不会跟随单位移动。** 识别到的坐标会明确标注“脚本初始位置”，跳转后该单位可能已经离开。区域若被运行时移动，所列范围也只是脚本定义。地图自己的镜头锁定、剧情控制和相机边界可能使视角被拉回或限制可见位置。本功能不取消这些地图逻辑，也不解除战争迷雾。

官方战役若只能读取安装包基础脚本，而本地覆盖层尚未确认，会继续显示原有来源提示；点击定位时沿用现有来源策略拒绝未确认的绑定，避免把可能已被覆盖的坐标当作当前位置。

## 独立相机入口

按用户最新选择，仅新增操作 325，用现有 profile 验证的 `PanCameraToTimed` 移动本地视角。请求只含坐标和当前地图会话令牌，不含单位参数。原有操作号、读取进程／单位实现、native 参数及签名表没有改动。

新 EXE/helper 配对协议为 82，以便拒绝误连旧 DLL。R24、R25 交付文件保留。R26 仅在本地交付，未发布到 GitHub。
