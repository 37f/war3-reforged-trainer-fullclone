# v2.2.4 FullClone R32-Test

将截至R31.14的FullClone累计扩展迁入原作者v2.2.4（源码9292b4f6ee40，发布EXE 54AA78D2D418）。本次直接上传已经交付的EXE和完整源码ZIP，没有为发布重新编译。文件版本2.2.4.332。

## 本版变化

- 保留作者v2.2.4的界面对比度、表格、字体与背包名称显示改进。
- 保留ID目录和自定义地图目录中的添加物品／技能、生成单位、科技等级设置，以及三秒鼠标放置与取消。
- **按用户最终选择，两个目录的生成单位也服从大象面板归属开关。**关闭开关时给自己；开启后按“给自己／给选中单位所属玩家／给指定玩家”执行，包括中立敌对（25）和中立被动（28）。Ctrl+A仍始终复制给自己。
- 保留R31.14的中立外交模板往返修复、共享控制位保护和真正原始双向关系恢复。本次没有新增native操作号，生产FullClone DLL与R31.14相同。
- 原作者进程／单位读取函数、版本profiles与原生调用参数按现有路径保留。
