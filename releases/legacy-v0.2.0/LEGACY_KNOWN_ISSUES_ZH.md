# Legacy v0.2.0-Test 已知问题与发布边界

本次发布现有、已完整打包的v0.2.0-Test。v0.2.1仍为未完成修复草稿，没有生成交付EXE，本次不包含该草稿或声称其修复生效。

## 已反馈且本包尚未修复

1. 某些普通单位（曾反馈为苦工，涉及光环/临时效果）复制时会提示“部分技能未能复制到目标单位”。操作可能已经部分生效；出现提示后先读取核对，不要反复执行。
2. 复制/大量复制的落点仍在源单位附近分散，不会按鼠标指定位置创建。该行为在本版代码中仍存在。
3. 手动增加英雄等级时没有原生升级特效。不能把“没有特效”直接等同数值没有变化，需读取等级核对。

## 适配边界

- 目标游戏是Legacy **1.29.2.9231 x86**，不是Reforged 3.0，也不是所有Legacy补丁通用。
- 本包UI默认目标路径固定为`E:\Games\Warcraft III (Legacy)\Warcraft III.exe`。没有游戏路径选择器；仅把修改器复制到其他目录不会改变目标路径。其他安装路径需自行从源码调整UI及后端TARGET再构建，不能承诺此EXE直接适用。
- 对目标游戏EXE做精确SHA-256校验。已适配游戏EXE为`3f2ed0120d80578bf07e4423296dade1adfb959d59a2d20a7584224559570eed`，不同文件拒绝使用旧地址。
- 外壳为Windows x64，内含独立x86助手；无需安装Python。没有打包游戏、地图、存档。
- 快捷键默认关闭，启用后仅在已连接的Legacy游戏窗口位于前台时生效。换图/读档/返回菜单后重新连接。
- 复制不迁移任意地图脚本变量、触发器引用、所有临时效果等，不承诺任意地图无损复制。某些旧地图中立编号是13～16，应以本图实际映射为准，不直接套用重制版25/28。
