# v1.0.19 FullClone R19.2

目标游戏：**Warcraft III 2.0.4.23745**。这是基于原作者 `4124cd5` 源码的非官方扩展版，不代表原作者发布。R19.1、R18、R16 发布及附件保留，便于回退。

## 本次修复

修复部分自定义战役单位的“玩家＋队伍监视”出现 `status=3 last_error=13`：这些单位归属的玩家存在，但未分配普通队伍，原生队伍值为 `-1`，旧监视将其误判为无效数据。

- 现在显示“玩家编号（可读取的实际名字）：未分配普通队伍（原始值 -1）”。
- 名字没有可读取内容时，按原有规则单独提示，不再阻断有效的玩家归属和队伍状态。
- 不把 `-1` 误算为队伍0、队伍1、中立敌对或中立被动。
- 只兼容现有只读监视操作317；身份/选择变化检查仍在，其他无效队伍值仍拒绝。旧操作316及加入/恢复队伍、控制、复制、归属等修改功能保持原样。
- native profile、哈希、调用签名、操作号和协议布局不变；协议仍为76，但 helper 已重新编译，升级必须完整重开游戏。

## 保留的历次扩展

- 面板复制归属开关，给自己/选中所属玩家/指定玩家（含中立）的选择；面板复制、大量复制、`Ctrl+B`、呼叫增援按开关执行，`Ctrl+A` 始终复制给自己。
- 无需预读的完整复制事务：英雄等级/经验、永久三围、技能点、技能及等级、HP/MP、背包数量和作者开放的物品字段。
- 转移单位归属、选中玩家控制/恢复、队伍1～12及中立外交模板、首次原队伍和双向关系恢复。
- 替换单位（默认 `zhyd`）、生命魔法全满、碰撞切换、单位/玩家颜色、选中玩家阵亡英雄复活。
- 英雄等级默认每次+1/自定义等级，永久三围默认各+2/自定义值，选中金矿剩余黄金设置。
- 鼠标位置释放 `AUin` 地狱火、直接胜利的秘籍/本地玩家模式。
- R18 全光环、全被动、六神器、全屏群星修复，以及 R16 大量复制归属参数修复。
- R19 实际玩家名字与队伍合并监视、R19.1 两个中立槽位的名字提示精简。

不包含已移除的游戏速度、单位/英雄改名和每秒推进约20秒建造/研究功能；`Alt+V` 保留原 `warpten`。
