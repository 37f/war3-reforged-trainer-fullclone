# 魔兽争霸 III 重制版修改器 v2.2.7 FullClone R36-Test

本次为预发布，基于原作者 v2.2.7 源码 `2211ad0846fb`，保留累计 FullClone 扩展。适用于 Windows x64 和《魔兽争霸 III》重制版 3.0 系列，具体功能取决于游戏构建与地图。

## 新增操作历史与单次撤销

进入「大象功能 → 目标玩家 → 操作历史」。展开条目可查看当前地图最近 30 次单位转交和外交模板操作涉及的目标、前后状态与逐项结果。面板、快捷键和队伍页拖放共用同一份记录。

- **单位转交**。单位从玩家 1 转给玩家 2，再转给玩家 3，撤销第二条后回到玩家 2。
- **外交模板**。可恢复本次操作前的外交关系及模板分组，共享控制权限保留当前值。
- **状态校验**。同一目标有更新的待撤销操作时，先处理更新的记录。单位身份、归属或相关外交关系变化后，相应目标会跳过并显示原因。换图后按新会话记录。
- **原始状态恢复**。「恢复真正原玩家／队伍」继续以首次修改之前的状态为准。
