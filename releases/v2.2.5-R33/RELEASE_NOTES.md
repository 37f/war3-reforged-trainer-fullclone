# v2.2.5 FullClone R33 正式版

基于[原作者 v2.2.5](https://github.com/dc114154qq/war3-reforged-trainer/tree/967a5cb20be3)，收录截至本地 R38 的 FullClone 累计扩展。公开版本编号为 R33。

## 2026-11-20 更新

- 加快「队伍与玩家」和「大象功能」的全部原队伍恢复。槽位身份无法确认时保留其记录，继续恢复其他可核验玩家。
- 中立敌对、中立被动及非活跃槽位支持拖放外交模板。恢复「队伍与玩家」记忆模式，换图时清除上一张地图的数据。
- 恢复整页滚动。拖住玩家卡片时可用鼠标滚轮上下滚动，再松手放到目标队伍。
- 大象功能新增「把选中单位恢复真正原玩家」和「恢复所有真正原玩家」。首次转交记录由面板按钮与 Ctrl+I+U 共用，限当前地图会话。单个外交恢复按钮改名为「把选中玩家恢复真正原队伍」。

## R33 原有发布内容

- 新增「游戏中名字／地图配置名」切换，大象扩展、快捷键、队伍与玩家及任务页支持中英文界面。
- 拖放外交模板在成功回执后直接更新人数和玩家信息，补齐玩家名称短暂失读的处理。
- 收录全军补满、地面物品按 ID 聚集、复制阵型、部队冻结与恢复、自定义补给包、鼠标位置技能及任务分析改进。
- 自定义任务可查看原文和已解析的条件。可匹配的 JASS 任务能读取状态，Lua 目前提供静态分析。

附件提供 Windows 单文件 EXE、完整源码 ZIP、[累计更新记录](https://github.com/37f/war3-reforged-trainer-fullclone/blob/v2.2.5-fullclone-r33/source-v2.2.5/R33_CHANGELOG_ZH.md)和 SHA-256 校验清单。旧版本接口及操作有变化时，以累计更新记录中的当前行为为准。

本次更新通过 395 项自动化测试，另有 1 项上游源码对照测试因独立源码包布局跳过。三套界面的按住卡片滚轮、拖放、记忆模式和单位归属按钮使用模拟游戏数据验证。本次验证未覆盖实机游戏写入。
