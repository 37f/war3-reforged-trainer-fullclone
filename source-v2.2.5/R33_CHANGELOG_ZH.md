# v2.2.5 FullClone R33 更新记录

R33 是 FullClone 的公开正式版本号。它以原作者 v2.2.5（提交 `967a5cb20be3`）为基础，合入截至本地 R38 的累计改动。Windows 文件版本 `2.2.5.338` 对应这次发布所用的构建。R33 至 R38 曾作为本地测试编号，下面按实现阶段记录它们的变化，便于对照旧说明。

## 相比公开 R32 的改动

| 开发阶段 | 已合入正式版的改动 |
| --- | --- |
| R33 | 迁移到原作者 v2.2.5，保留新版搜索、筛选、输入草稿和栏目排序。Lua 任务分析新增对标准匿名回调、简单布尔组合及部分文字包装函数的识别。 |
| R34 | 新增选中玩家全军补满生命和魔法，可选择全部、仅英雄或仅非英雄。地面物品聚集支持按四字符 ID 包含或排除。没有匹配的物品时，游戏里的物品保持原位。 |
| R35 | 大量复制加入方阵、圆环、直线和分散阵型，间距可调。新增冻结与恢复整支部队、三组自定义补给包，以及鼠标位置的地狱火、暴风雪、烈焰风暴和火焰雨。 |
| R36 | 任务按主线和支线展示，保留目标原文和完成、失败条件。可用的官方中文原文会按游戏文字语言读取，唯一匹配的 JASS 任务会同步实时状态。`Ctrl+空格` 绑定全军补满，`Ctrl+F2` 绑定当前选中的鼠标位置技能。 |
| R37 | 玩家名称短暂失读时保留同图上次读值，已确认的地图中英名称按游戏文字语言显示。拖放外交模板收到成功回执后马上更新卡片、人数和详情。地狱火的独立按钮并入鼠标位置技能。 |
| R38 | 队伍与玩家取消记忆模式，加入「游戏中名字（含玩家昵称）」与「地图配置名」切换。切到 English 后，大象扩展、快捷键、队伍与玩家和任务与条件的控件及程序生成说明一起切换。玩家昵称和地图提供的文字原样显示。 |

## 更早版本的累计改动

| 公开版本或开发阶段 | 主要改动 |
| --- | --- |
| 1.0.19 / R19.2–R19.3 | 修复自定义战役中未分配普通队伍时的玩家名和队伍监视。可给这类玩家套用外交模板，并恢复首次改动前的双向外交关系。 |
| R20–R21 | 可只读检索战役文件和章节的自定义物品、技能、单位等 ID，后来加入当前运行地图的直接检索。 |
| R22–R24 | 加入当前地图的主支线任务分析，覆盖官方战役、自定义战役和独立地图。R23 曾试验执行任务原流程，R24 撤回该入口并保留只读任务信息。 |
| R25–R29 | 同步可唯一匹配的 JASS 任务状态。可定位触发区域、对象初始位置、物品掉落、刷新和传送等明确地点。原说明始终显示，勾选「触发位置」才展开地点与视角跳转。 |
| R30–R31.5 | 将累计扩展迁到原作者 v2.2.3 的 3.0 版基础，加入地面物品聚集、复制归属等操作，并提供现代深色、白色标签页和 1.0.19 旧式三套界面。 |
| R31.7–R31.14 | 加入队伍与玩家列表、玩家和单位监视、外交模板拖放及单个或全部关系恢复。修正共享控制被误复制、中立敌对与被动拖回原模板后关系未正确恢复等问题。加入 Lua 任务的静态读取。 |
| R32 | 迁到原作者 v2.2.4。通用 ID 目录和自定义地图目录的单位生成服从大象面板归属开关，关闭时给自己。`Ctrl+A` 仍固定复制给自己。 |

## 当前行为和使用范围

- 适用于 Windows x64 的 Warcraft III 重制版 3.0 系列。列明的构建为 `3.0.0.24268`、`3.0.1.24323`、`3.0.1.24332`、`3.0.1.24342`、`3.0.1.24360`、`3.0.1.24365` 和 `3.0.1.24371`。任务自动定位和实时绑定还有精确构建和脚本条件。
- `Ctrl+空格` 按面板范围补满选中单位所属玩家的存活且未隐藏单位。单单位补满可从面板点选。`Ctrl+F2` 按面板选定技能施法，`Alt+F2` 按 ID 筛选聚集地面物品。面板施法按钮保留三秒鼠标放置时间。
- 队伍拖放套用外交关系模板。首次改动前的关系保存在当前修改器会话，准备切换版本时可在旧窗口先完成所需的恢复。
- 任务分析为只读。Lua 可展示可靠识别的静态信息，实时状态仍待适配。单位地点若只取到脚本初始坐标，界面会标注其来源。
- 本次发布对 EXE、源码和校验文件做完整性核对。游戏行为的验证范围以发布页的验证说明为准。
