# R26 任务地点展示与相机定位实施记录

基线：R25 本地提交 `a6f5420`。范围：任务条件展示、位置解析及一个独立的本地相机操作。用户在确认“不增加 native 入口”后，随后明确改选第一个方案；按最新选择允许独立相机入口，保留既有读取与 native 调用逻辑。

## 文件

- `source/war3_quest_locations.py`：只从现有 ScriptSnapshot 的 JASS 解析区域、地点及单位初始坐标；按照原 ConditionPath 的事件和 guard 查关联，不改变 guard。
- `source/war3_quest_text.py`：在原条件解释后追加地点列表／无位置。合并显示多条路径时，保留各路径的全部关联地点。
- `source/war3_quest_ui.py`：沿用任务树与详情，增加条件／地点子行、蓝色链接和无位置提示；后台生成位置索引；只有明确点击／Enter 才定位。
- `source/war3_reforged_trainer.py`：新增 `show_quest_location` 与 UI 回调。复用来源校验和串行通道，不修改既有进程／单位读取方法。
- `source/tools/war3_quest_camera.h`：操作 325，检查当前活跃会话、有限坐标、原生表签名及代码指纹后调用本地相机。没有单位、任务 setter 或触发器执行。
- `source/tools/war3_native_helper.c`：仅配对协议 82、新操作号、独立 include／分派和零 handler 许可。已有操作体不变。
- R26 独立 spec、版本信息、包校验器和使用说明；`war3_runtime_check.py` 配对检查改为 82。

## 检查

第一轮范围检查 149 项通过。包括实际 C 相机适配器夹具的 float 指针 ABI、旧会话拒绝、非有限坐标拒绝及无单位参数；任务位置歧义、多个地点、无位置、UI 程序化刷新不移动视角、原条件说明及状态同步回归。最终数量见交付核对记录。

用用户现有《雷克萨之书》战役的 `K-ValleyOfTrial.w3x` 文件作只读脚本样本，识别到入侵者、邪恶的威胁、回音群岛、萨科斯、塔兹利尔的镐等任务的关联矩形中心与范围。百科条目没有条件地点时保留无位置。此项是实际文件解析，不等于实测相机已跳转。

对当前游戏中 `PanCameraToTimed` 的代码作有界被动读取，其首 64 字节 FNV64 为 `e0ed7167495743bc`，与已有 profile 一致。REA 原生分析工具在本会话不可用，沿用现有 Capstone／只读进程接口核对；未修改工具注册或游戏代码。相机指纹核对不等于已执行相机或看到画面。

## 保留边界

动态单位当前位置不读取；初始位置明确标注。未知、多重冲突或不支持的表达式不猜坐标。点击到执行期间由原来源校验及游戏侧会话令牌拒绝换图。相机受地图自身镜头控制和边界限制。未改任务判定语义、读取进程／单位参数、native 签名表，也未恢复任务执行。
