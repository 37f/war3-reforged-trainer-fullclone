# 魔兽争霸 III 重制版修改器 v2.2.7 FullClone R36-Test

本版以原作者 v2.2.7 源码 `2211ad0846fb` 为底，迁入已发布的 v2.2.6 FullClone R34 的累计扩展。适用于 Windows x64 的《魔兽争霸 III》重制版 3.0 系列，具体可用功能取决于游戏构建和地图。

## 大象功能 · 操作历史与单次撤销

在「大象功能 → 目标玩家」展开「操作历史」。列表收录当前地图最近 30 次有结果的单位转交和外交模板操作，包含面板、快捷键和队伍页拖放。展开一条记录，可查看每个单位的类型 ID 和玩家变化，或查看玩家的模板变化。

- 点「撤销这次操作」，会把可核验的目标恢复到该条记录操作前的状态。单位从玩家 1 给玩家 2，再给玩家 3，撤销第二条后回到玩家 2。
- 同一目标有更新的待撤销记录时，先撤销更新的记录。当前单位身份、归属或外交关系已变化时，对应目标会跳过，原因显示在记录中。
- 「恢复真正原玩家／队伍」仍可恢复首次修改之前的状态。它成功后，相应的旧撤销项会标记为失效。撤销记录只在当前连接的地图会话内有效。

## v2.2.7 原版更新

- 选定玩家的金币、木材、已用人口和人口上限能够持续锁定。某项暂时写入失败时，其余锁定项可以继续处理。
- 失败弹窗显示可识别的具体原因。批量操作列出已处理目标和失败原因，操作后的界面刷新失败会单独提示。
- 存档扫描遇到不可读取的目录时继续扫描其他位置，并列出跳过的目录。

## FullClone 扩展

- **大象功能**。复制归属、阵型大量复制、替换单位、全军补满生命魔法和冻结／恢复、补给包、鼠标位置技能及地面物品聚集。两个 ID 目录的「生成单位」服从大象面板归属选择，`Ctrl+A` 固定复制给自己。
- **队伍与玩家**。切换游戏中名字和地图配置名、监视玩家与队伍、查看或拖放外交模板、恢复单个或全部玩家原队伍。单位转交记录支持恢复选中单位或当前地图内全部已记录单位的原归属。按住玩家卡片时用鼠标滚轮上下移动名单。
- **任务与条件**。手动检测当前地图，读取主支线任务说明和可解析的完成／失败条件。勾选「触发位置」显示可定位地点，点击对应位置可跳转本地视角。能唯一匹配的 JASS 任务显示实时状态，Lua 提供静态解析，实时状态尚未适配。
- **界面**。支持现代深色、白色标签页和 1.0.19 旧式布局。扩展界面可切换中文或英文，地图文字与玩家名称取自游戏或地图数据。

更早的累计改动与快捷键见 [R33 更新记录](R33_CHANGELOG_ZH.md)。

## 从源码构建

需要 Windows x64、Python 3.12 和 Node.js 22。源码包附已构建的前端和本版桥接组件。运行以下命令前，把第一条 `--from-file` 的值换成作者 v2.2.7 原版 EXE 的实际路径。如修改了前端源码，先运行 `npm ci --prefix frontend` 和 `npm run build --prefix frontend` 更新前端产物。

```powershell
python -m pip install -r requirements-build.txt
python tools/prepare_build_baseline_227.py --from-file 'War3ReforgedTrainer-v2.2.7-D0954D1C8846.exe'
python tools/build_fullclone_release_227.py --bridge-image tools/war3_bridge_24268.dll
python tools/build_fullclone_release_227.py --verify-only
```

构建产物 `War3ReforgedTrainer-v2.2.7-FullClone-R36-Test.exe` 位于 `dist-2.2.7-fullclone-r36-test-verified`。
